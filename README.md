# Customer Spending Prediction Using Machine Learning

## ML Workshop Project

### Problem Statement
**Customer Spending Prediction**

### Objective
Predict a customer's total spending using demographic and purchasing-behavior features.

This project follows the workshop workflow and demonstrates both regression and classification.

## Dataset

For this fully offline submission, a reproducible synthetic dataset is generated by `run_project.py`.

It contains 2,240 customer records with features such as:
- Age
- Income
- Education
- Marital Status
- Recency
- Web, catalog and store purchases
- Web visits
- Household children/teenagers
- Complaint and campaign response

The target is `Total_Spending`.

**Important:** `Total_Spending` is not supplied as an input feature, avoiding target leakage.

## Machine Learning Models

### Regression
1. Linear Regression using Income as a single-feature baseline
2. Multiple Linear Regression
3. KNN Regressor

### Classification extension
Customers are classified as Low Spenders or High Spenders using the **training-set median spending** as the threshold.

Models:
1. Logistic Regression
2. KNN Classifier
3. Bernoulli Naive Bayes

## Evaluation Metrics

### Regression
- MAE
- RMSE
- R²

### Classification
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion Matrix

## Verified Offline Results

### Regression

| Model | MAE | RMSE | R² |
|---|---:|---:|---:|
| Multiple Linear Regression | 73.950 | 92.558 | **0.955** |
| KNN Regressor | 169.932 | 217.179 | 0.750 |
| Linear Regression (Income only) | 202.975 | 256.959 | 0.650 |

**Best regression model: Multiple Linear Regression**

### Classification

| Model | Accuracy | Precision | Recall | F1 | ROC-AUC |
|---|---:|---:|---:|---:|---:|
| **Logistic Regression** | **0.920** | **0.922** | 0.914 | **0.918** | **0.985** |
| KNN Classifier | 0.848 | 0.852 | 0.836 | 0.844 | 0.918 |
| Bernoulli Naive Bayes | 0.810 | 0.785 | **0.845** | 0.814 | 0.901 |

**Best classification model: Logistic Regression**

## Conclusion

Multiple Linear Regression provides the strongest regression performance in this experiment. Logistic Regression provides the strongest classification performance. The project compares multiple models and uses appropriate evaluation metrics rather than relying on a single score.

The dataset is synthetic and reproducible because the project was designed for a fully offline workshop environment.
